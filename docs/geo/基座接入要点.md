## Schema 硬约定（docs/PLATFORM-SCHEMA.md）
- 主键 `String @id @db.VarChar(26)` 应用层 ULID，无 `@default`
- 租户表 `tenantId String` NOT NULL；`@@index([tenantId, id])`；软删表唯一索引带 `deletedAt`
- 金额 `Int` 且以 `Cents` 结尾；禁 Decimal/Float。token 用量等非金额用普通 Int
- 状态用 Prisma enum；`createdAt @default(now())`、`updatedAt @updatedAt`、软删 `deletedAt DateTime?`
- **一条 relation 都不建**，用 `xxxId String` + 应用层 join
- 不做 @map；平台域表来源租户列叫 `originTenantId`，不叫 `tenantId`
- `00-base/**` 框架托管勿手改；框架源在 `packages/prisma-base/schema/*`，改后需 `taizan:schema-sync` 重新生成 `base.lock.json`

## 数据访问
```ts
✅ this.prisma.tenant.goods.findMany({ where: { status } })     // 绝不写 tenantId
✅ create({ data: autoTenantData<Prisma.GoodsCreateInput>({...}) })
❌ where: { tenantId, ... }   // arch spec 会红
```
跨租户走 `RawPrismaService` + `src/tenancy/raw-reasons.ts` 登记 + `// raw-reason:` 注释。

## 计费
- 功能开关 `registry/features.ts`；配额 `QuotaKind` 枚举在框架 `02-plan.prisma`（STAFF|STORE|MEMBER|STORAGE_MB|TRAFFIC_MB|CUSTOM），顶栏档位登记在 `registry/quota-kinds.ts`
- `await quota.consume(kind)` 先占再写库，失败 release；删除时 release
- 三态：`null`=不限，`0`/`[]`=一个都不给。四个独立错误码 1440301/1440302/1540301/1540302

## 队列/cron/通知
- `@JobHandler({ name, concurrency, attempts, backoff, deadLetter })` + `process(env: JobEnvelope<P>)`；`queue.add(name, payload, { tenantId })`；入队在写库成功之后、事务之外；handler 内可用 `prisma.tenant`
- cron 只许 `@LeaderCron({ key, cron, lockTtlMs, watchdog })`，禁裸 `@Cron`/`setInterval`；进程内 Map/Set 必须标 `// process-local:` 理由
- `notify.send({ tenantId?, templateKey, to, vars, channels?, fallback? })`；模板在 `registry/notify-templates.ts`
- 缓存 key 强制租户前缀

## tsup/esbuild 限制
无 emitDecoratorMetadata：注入一律显式 `@Inject(Token)`；DTO 校验一律 `@Body(Validate(Dto))`；`@ApiProperty({ type })` 显式。

## 认证/权限
- `@RequirePermission('a:b')`（支持 `'a|b'` 或、`['a','b']` 与；禁通配）
- `@Public()` 必须同时 `@RateLimited(tier)`
- 密钥落库用 `TenantCredential` + `@taizan/crypto` CredentialVault，`*Enc` 列必须配 keyId 列
- IP 只能用 `resolveIps`

## 前端
- admin-ui：`useCrudTable` + `useCrudForm` + `CrudTable` + `CrudDrawerForm` + `Perm`；页面里不该有 useState/useEffect
- 路由由服务端菜单 `componentKey` 下发，`component-map.ts` 登记；改菜单后跑 `pnpm -F @taizan/admin sync-menus`
- 全仓没有图表库；引入 `@ant-design/plots` 需加到 apps/admin/package.json 并确认 build 绿
- platform 端加页面同形；下钻页可不进 component-map，路由在 App.tsx 手工加

## 完全没有的能力
LLM/AI 零封装。新建 `packages/llm`，照 `packages/sms` 形状：零框架依赖 + Provider 接口 + registry 主备切换 + mock 兜底 + spec。
